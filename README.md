## 数据清洗相关
- 健身中心的早期数据（如5.8）的最早时间段是7:00-8:30, 8:30-10:00，10:00-11:30而在5.10之后则改成了6:30-8:00, 8:00-9:30, 10:00-11:30。因此对于最早期5.8和5.9的数据，我们将早上两个时间段响应对齐到调整后的时间段。
- 5.31早晨没有数据是因为体育馆自即日起，每周日6:30-9:30检修游泳馆、健身中心设备，暂停开放。具体见[关于游泳馆、健身中心周日晨间时段暂停开放的通知](https://cgyy.qd.sdu.edu.cn/venue/homeArticle?id=91&type=2)

## 数据分析相关：
- 可以发现几乎每天周三都是满员，都是到6月1日为止，有5个异常值，最后一个是因为还没爬取；而前四个，根据热力图可以得知，异常值都是在周日的，因此可以发现，大部分人周日的中午12点是不愿意健身的，而平时的中午12点则相反。而相反的，平时人数很多但没满员的16:00-17:30，在周日依旧维持高人数。说明周日，健身的意愿都维持在下午
